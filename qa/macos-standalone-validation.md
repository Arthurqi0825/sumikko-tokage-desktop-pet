## 签名说明

当前构建使用 adhoc codesign，保证包内完整性，但没有 Apple Developer ID 与 notarization。因此 `spctl` 拒绝属于预期结果；个人本机测试可右键选择“打开”。若要公开分发，需要配置 Developer ID Application 证书，对 `.app` 签名，提交 Apple notarization，再执行 stapling。
